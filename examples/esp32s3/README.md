# ESP32-S3 Display Driver Examples

This repository contains examples demonstrating how to drive various screens using [esp-hal](https://github.com/esp-rs/esp-hal/) on the ESP32-S3. It showcases the use of hardware QSPI.

For detailed instructions on toolchain configuration, compilation, and flashing, please refer to [The Rust on ESP Book](https://docs.espressif.com/projects/rust/book/getting-started/toolchain.html).
